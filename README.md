IP LOOKUP TOOL

JARDECODER is a Python-based IP Lookup tool that retrieves IP address information and approximate geographical locations.

✨ Features
🌐 Domain IP Lookup
📡 Own Public IP Lookup
🌍 Country Information
🏙️ Region and City Information
🛜 ISP Information
📍 Latitude and Longitude
🗺️ Google Maps Location
💾 Automatic TXT Report Saving
🎨 Terminal Interface
📱 Supported Platforms
Kali Linux
Debian / Ubuntu
Android (Termux)
📦 Requirements
Python 3
Internet connection
Requests library
Chafa (optional)
🚀 Installation
1. Termux (Android)

Update packages:

bash
pkg update && pkg upgrade -y


Install dependencies:

bash
pkg install python git chafa -y


Clone repository:

bash
git clone https://github.com/USERNAME/JARDECODER.git


Enter directory:

bash
cd JARDECODER


Install Python requirements:

bash
pip install -r requirements.txt


Run JARDECODER:

bash
python jar_ip.py

2. Kali Linux

Install dependencies:

bash
sudo apt update
sudo apt install python3 python3-venv chafa git -y


Clone repository:

bash
git clone https://github.com/USERNAME/JARDECODER.git
cd JARDECODER


Create virtual environment:

bash
python3 -m venv .venv


Install requirements:

bash
.venv/bin/pip install -r requirements.txt


Run:

bash
.venv/bin/python jar_ip.py

📂 Output

Lookup reports are saved as:

text
~/hasil_ip.txt
